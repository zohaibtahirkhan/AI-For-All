# Solutions

Solutions are intentionally not included in this repository.

## Why?

The best learning happens when you struggle with the problem first. Looking at solutions prematurely robs you of the "aha" moment that makes knowledge stick.

## How to Use Solutions

1. **Attempt every exercise** — even if you're not sure, write something
2. **Run your query** — see what it returns, debug if wrong
3. **Only then** look for alternative approaches online or ask for help

## Getting Help

- **PostgreSQL docs**: https://www.postgresql.org/docs/
- **Stack Overflow** — search your specific error or pattern
- **Mode SQL Tutorial**: https://mode.com/sql-tutorial/
- **pgexercises.com** — more SQL exercises
- **Claude** — explain your query and ask what's wrong or how to optimize it

## Submitting Your Solutions

Once you complete a day, consider:
1. Creating a `solutions/` folder in your fork
2. Adding your solution SQL files
3. Opening a PR — comparing solutions is a great learning tool!

---

*The goal is not to copy solutions. The goal is to become a Data Engineer who can write these queries from memory (Or just know how to write those).*
